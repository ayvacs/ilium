# ilium (/ ˈɪliəm /)

is the widest and largest region of the hipbone of most vertebrates; it is also a free archive of ancient texts built with 11ty

## installation

<a href="https://nodejs.org/en/download">install npm</a> and use it to install 11ty everywhere:

```
npm install -g @11ty/eleventy
```

after that, you can serve it to your local browser:

```
cd ilium
eleventy --serve
```
